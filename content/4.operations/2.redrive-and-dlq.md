# Redrive and dead letters

`failed` rows **are** the dead-letter set. They stay hot for inspection (`queues.failed_retention_hours`, default 14 days).

```sql
SELECT * FROM taskq.dead_jobs LIMIT 50;
SELECT taskq.redrive_job(id, 'operator:admin') FROM taskq.jobs
WHERE status = 'failed' AND queue = 'courts' AND outcome = 'poison';
```

Redrive resets budgets and returns the job to `queued`. If another active job already holds the same idempotency key, redrive fails with `TQ409`.

Optional lineage columns support a separate dead-letter queue when a product needs an ops inbox.

# Configuration

## Queue profiles

Rich defaults live on `taskq.queues` and are stamped onto each job at enqueue:

- `max_attempts`, lease seconds, retry backoff
- default priority
- retention windows
- optional depth limit

Changing a queue profile affects **future** enqueues only.

## Worker knobs (keep tiny)

| Knob | Default |
|---|---|
| `queues` | required |
| `concurrency` | 1 |
| `batch` | 1 |
| `poll_interval` | 5s |
| `listen` | true |
| `soft_stop_timeout` | none (wait forever) |
| `worker_id` | required |

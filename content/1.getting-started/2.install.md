# Install

```bash
pip install outlabs-taskq           # core: SQL client + worker runtime
pip install outlabs-taskq[http]     # + FastAPI facade / HTTP worker client
pip install outlabs-taskq[outlabs]  # + outlabs-auth adapter for facade auth
```

Requires **Python 3.12+** and **PostgreSQL 16+** (18 is the deploy target).

## Dependency tiers

| Install | What you get | Hard deps |
|---|---|---|
| `outlabs-taskq` | Installer, models, asyncio SQL client, worker loop, CLI | pydantic, sqlalchemy[asyncio], asyncpg, croniter |
| `[http]` | Facade router + HTTP client | fastapi, httpx |
| `[outlabs]` | SimpleRBAC permission adapter | outlabs-auth |

**Hard rule:** `import taskq` must succeed without FastAPI and without `outlabs-auth`.

## Install schema

```python
from taskq.sql import install, verify

await install(conn, schema="taskq")
assert (await verify(conn)).ok
```

Host apps typically call `install()` from a single Alembic/migration revision rather than forking SQL in-tree.

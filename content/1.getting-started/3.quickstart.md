# Quickstart

> API sketches below match the design contract. Function names stabilize as the package lands on PyPI.

## Define a task

```python
from datetime import timedelta
from taskq import Blueprint, Complete, Snooze, TaskQ

courts = Blueprint()

@courts.task(queue="courts", job_type="scrape_county", retry=5)
async def scrape_county(ctx, payload: dict):
    if quota_hit():
        return Snooze(delay=timedelta(hours=1), reason="provider_quota")
    data = await do_scrape(payload)
    return Complete(result={"n": len(data)})

tq = TaskQ(dsn="postgresql+asyncpg://...")
tq.add_tasks_from(courts, namespace="courts")
```

## Enqueue (insert-only client)

```python
# No queues configured → producer only; does not start a claim loop
result = await tq.enqueue(
    scrape_county,
    {"county": "Boone"},
    idempotency_key="courts:Boone:2026-07-18",
)
# result.status in {created, existed, replaced, skipped_locked, conflict}
```

## Run a worker

```python
worker = TaskQ(
    dsn="postgresql+asyncpg://...",
    handlers=tq.handlers,
    queues=["courts"],
    worker_id="box:courts:1",
)
await worker.run()
```

## HTTP topology

If workers must not hold DB credentials:

1. Mount the FastAPI facade in your API process (with optional outlabs-auth deps).
2. Run the housekeeper (`tick`) in the API process.
3. Point workers at the HTTP client (`X-API-Key` or Bearer).

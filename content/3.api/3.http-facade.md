# HTTP facade

Some worker fleets must not hold database credentials. Mount the optional FastAPI router in your API process:

```python
from taskq.http import create_router
from taskq.http.outlabs import outlabs_permission_auth  # optional extra

app.include_router(
    create_router(
        get_client=...,
        auth=outlabs_permission_auth(
            auth=auth,
            session_dependency=get_async_session,
            read=("job:read",),
            write=("job:write",),
        ),
    ),
    prefix="/api/v1/taskq",
)
```

## Auth is injected

The facade does **not** import `outlabs-auth` by default. Hosts pass a `TaskqAuth` dependency pair. Built-ins include static API key and bearer adapters for labs that do not use OutLabs IAM.

## Topology rule

HTTP workers never call `tick`. The facade host runs the housekeeper coroutine.
